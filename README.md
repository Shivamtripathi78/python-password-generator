# 🔐 Python Password Generator

A command-line password generator built with Python's `secrets` module.

## Features

- Customizable password length from 4 to 128 characters.
- Optional uppercase letters.
- Optional numbers.
- Optional special characters.
- Secure random character generation.
- Input validation.

## Technologies Used

- Python 3
- `secrets`
- `string`

Both modules are included in Python's standard library.

## Getting Started

### Installation

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/python-password-generator.git
```

Navigate to the project:

```bash
cd python-password-generator
```

Run the application:

```bash
python main.py
```

## How to Use

1. Enter the desired password length.
2. Choose whether to include uppercase letters.
3. Choose whether to include numbers.
4. Choose whether to include special characters.
5. Copy the generated password and store it securely.

## Security

This project uses Python's `secrets` module for secure random generation.

Generated passwords are displayed in the terminal and are not saved to a file.

For important accounts, use a reputable password manager.
